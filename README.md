# 📈 AFinancial: AI-Assisted Financial Intelligence and Decision Support System
## Project Overview
AFinancial is a personal financial analysis tool developed with Python. It is designed to help users analyse the relationship between stock market movements and financial news sentiment.

The system automatically collects historical stock data, processes financial news, performs sentiment analysis, and generates visual reports to provide insights into how market sentiment may relate to stock price changes.

This project is mainly developed for personal research, learning, and data analysis purposes. It does not provide investment advice or guarantee future market performance.

### Features
### 1. Stock data acquisition
**Use Yahoo Finance (yfinance) to obtain historical stock quotes, including:**
- Open
- High
- Low
- Close
- Volume

**Support custom stock codes, for example:**
- MSFT
- AAPL
- TSLA
- 0700.HK
### 2. Acquisition of financial news
**Get financial news with AkShare.**
If real News cannot be obtained, Mock News data will be automatically generated to ensure the normal operation of the entire analysis process.
### 3. Data cleaning
- Stock data
- Time sorting
- Missing value handling
- Log Return calculation
- News data
- duplicate removal
- Date format conversion
- Date standardization
### 4. News sentiment analysis
Adopt NLTK VADER Sentiment Analyzer
**Calculate each piece of news:**
- Positive
- Negative
- Neutral
- Compound Score
- Then calculate the average daily mood value.
### 5. Data fusion analysis
**According to the date:**
- Stock return rate
- News sentiment
- Perform a Merge
- Calculation
**The correlation between the mood of the day and the rate of return**
- Next-day yield correlation (Lag Analysis)
### 6. Automatically generate reports
Automatically generated by the system
Markdown Report
**And output:**
- Stock trend chart
- Trading volume
- Emotional changes
- Correlation heat map

## Main analysis of the project:

Return = ln(Pₜ / Pₜ₋₁)

**Where:**

- Pₜ = Closing price at time *t*
- Pₜ₋₁ = Closing price at time *t−1*


### Sentiment Score
**Range：**
```
-1  ← Negative

 0  ← Neutral

+1  ← Positive
```

### Pearson Correlation
Calculation：
```
Sentiment
        ↓
Stock Return
```
It is used to measure the linear relationship between news sentiment and stock returns.
