# 📈 AFinancial: AI-Assisted Financial Intelligence and Decision Support System [v2.0.1]
## Project Overview
AFinancial is a Python-based financial analysis platform that integrates stock market data, financial news, sentiment analysis, statistical analysis, and AI-generated explanations into a single workflow.

The system automatically collects stock prices and financial news, analyses market sentiment, evaluates the relationship between news sentiment and stock returns, and generates both Markdown and Microsoft Word reports with beginner-friendly explanations.

This project is designed for learning, research, and educational purposes only.

## Main analysis of the project:

Return = ln(Pₜ / Pₜ₋₁)

**Where:**

- Pₜ = Closing price at time *t*
- Pₜ₋₁ = Closing price at time *t−1*


### Sentiment Score
**Range：**
```
-1  ← Negative

 0  ← Neutral

+1  ← Positive
```

### Pearson Correlation
Calculation：
```
Sentiment
        ↓
Stock Return
```
It is used to measure the linear relationship between news sentiment and stock returns.
