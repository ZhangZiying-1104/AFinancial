# 📈 AFinancial: AI-Assisted Financial Intelligence and Decision Support System [v1.2.0]
## Project Overview
AFinancial is a Python-based financial analysis platform that integrates stock market data, financial news, sentiment analysis, statistical analysis, and AI-generated explanations into a single workflow.

The system automatically collects stock prices and financial news, analyses market sentiment, evaluates the relationship between news sentiment and stock returns, and generates both Markdown and Microsoft Word reports with beginner-friendly explanations.

This project is designed for learning, research, and educational purposes only.

### Features
### 1. Stock data acquisition
**Use Yahoo Finance (yfinance) to obtain historical stock quotes, including:**
- Open
- High
- Low
- Close
- Volume

**Support custom stock codes, for example:**
- MSFT
- AAPL
- TSLA
- 0700.HK
### 2. Acquisition of financial news
**Get financial news with AkShare.**
If real News cannot be obtained, Mock News data will be automatically generated to ensure the normal operation of the entire analysis process.
### 3. Data cleaning
- Stock data
- Time sorting
- Missing value handling
- Log Return calculation
- News data
- duplicate removal
- Date format conversion
- Date standardization
### 4. News sentiment analysis
Adopt NLTK VADER Sentiment Analyzer
**Calculate each piece of news:**
- Positive
- Negative
- Neutral
- Compound Score
- Then calculate the average daily mood value.
### 5. Data fusion analysis
**According to the date:**
- Stock return rate
- News sentiment
- Perform a Merge
- Calculation
**The correlation between the mood of the day and the rate of return**
- Next-day yield correlation (Lag Analysis)

### 5. AI Module
- AI-powered financial explanations
- Beginner-friendly interpretation
- Educational recommendations

### 6. Automatically generate reports
- Automatically generated by the system
- Markdown Report

**And output:**
- Stock trend chart
- Trading volume
- Emotional changes
- Correlation heat map
- Microsoft Word (.docx) report export

## Main analysis of the project:

Return = ln(Pₜ / Pₜ₋₁)

**Where:**

- Pₜ = Closing price at time *t*
- Pₜ₋₁ = Closing price at time *t−1*


### Sentiment Score
**Range：**
```
-1  ← Negative

 0  ← Neutral

+1  ← Positive
```

### Pearson Correlation
Calculation：
```
Sentiment
        ↓
Stock Return
```
It is used to measure the linear relationship between news sentiment and stock returns.
